# 🏝 Mystery of the Island | Выживание

Текстовое выживание с пиксельной графикой — Telegram Mini App.
Возрождение VK-бота «Выживание» (2020–2021).

- Три сложности: Турист, Выживший, Хардкор — отличаются механиками, а не только цифрами
- 11 локаций, база, крафт, торговцы, задания, выбросы и кровавые ночи
- Облачные сохранения через Telegram

Игра открывается кнопкой «Играть» в боте. Файлы раздаются через GitHub Pages.
